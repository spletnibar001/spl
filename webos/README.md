# ЭФИР для LG webOS

Тот же плеер, что и для Android TV: при включении сразу идёт последний канал,
список поверх видео, группы, поиск, избранное, скрытие каналов, набор номера, QR для телефона.

- `app/` - веб-приложение (HTML, CSS, JS на ES5 - работает и на webOS 3-4)
- `service/` - служба на телевизоре (Node.js): скачивает плейлист без ограничений браузера
  и поднимает страницу для телефона (порт 8080-8090), куда вставляется ссылка или файл `.m3u`
- `test/` - проверки: `service-test.js` (служба на обычном Node) и `ui-test.js` (интерфейс в Chromium 1920x1080)

## Установка на телевизор (режим разработчика)

1. Создайте бесплатный аккаунт на webostv.developer.lge.com.
2. На телевизоре: LG Content Store - приложение **Developer Mode**, войдите тем аккаунтом,
   включите Dev Mode Status (телевизор перезагрузится), затем включите Key Server.
3. На компьютере в той же сети: программа **webOS Dev Manager** (github.com/webosbrew/dev-manager-desktop) -
   добавьте телевизор по IP и коду из Developer Mode, затем установите `efir-webos.ipk`.
   Либо через ares-cli: `ares-setup-device`, затем `ares-install efir-webos.ipk`.
4. Режим разработчика работает 1000 часов. Чтобы приложение не удалилось, раз в месяц-полтора
   откройте Developer Mode на телевизоре и продлите таймер.

## Пульт

| Кнопка | При просмотре | В списке |
|---|---|---|
| ▲ ▼ | предыдущий / следующий канал | выбор канала |
| OK | открыть список | смотреть канал |
| удерживать OK | в избранное / убрать | меню: избранное, скрыть канал, скрыть группу |
| красная кнопка | в избранное / убрать | меню канала |
| ◀ | открыть список | предыдущая группа |
| ▶ | показать, что идёт | следующая группа |
| цифры | канал по номеру | - |
| CH+ / CH- | следующий / предыдущий канал | листать страницами |
| НАЗАД | дважды - выход | закрыть список |

Пульт-указка Magic Remote тоже работает: строки, вкладки и кнопки нажимаются курсором, колесо листает список.

## Отличия от версии для Android

- Кода transfiles.ru нет: сайт не даёт скачивать файл внутри встроенных страниц.
  Скачайте файл на телефон и отправьте его на телевизор через QR - «Выбрать файл .m3u».
- Заголовки User-Agent и Referer из плейлиста встроенный плеер телевизора не передаёт.

## Сборка

`ares-package webos/app webos/service` (пакет `@webos-tools/cli`). GitHub Actions собирает
`efir-webos.ipk` вместе с APK и кладёт оба в релиз `efir-tv`.
