# ЭФИР - плеер M3U для Android TV

Приложение ведёт себя как обычный телевизор: при включении сразу идёт последний канал,
список открывается поверх видео. Каналы не входят в приложение - подключается свой плейлист.

Эта ветка (`efir-tv`) живёт отдельно от сайта и броней SPLETNI и их не затрагивает.

## Пульт

| Кнопка | При просмотре | В списке |
|---|---|---|
| ▲ ▼ | предыдущий / следующий канал | выбор канала |
| OK | открыть список | смотреть канал |
| удерживать OK | в избранное / убрать | меню: избранное, скрыть канал, скрыть группу |
| ◀ | открыть список | предыдущая группа |
| ▶ | показать, что идёт | следующая группа |
| цифры | канал по номеру | - |
| CH+ / CH- | следующий / предыдущий канал | листать страницами |
| НАЗАД | дважды - выход | закрыть список |

Каналы при ▲▼ листаются внутри группы, из которой канал был выбран в последний раз
(например, только по избранному).

## Первый запуск

На экране QR-код: телефон в той же Wi-Fi сети открывает страницу, туда вставляется
ссылка на M3U или выбирается файл `.m3u`. Можно и ввести ссылку пультом.

Третий способ - код с transfiles.ru (символы после `transfiles.ru/`). Сайт перед скачиванием
просит ввести символы с картинки, поэтому его страница открывается внутри приложения:
вводите символы, нажимаете скачивание - плейлист загружается сам (обычный `.m3u` или zip).

## Группы и скрытые каналы

Каждая группа из плейлиста (`group-title`) - отдельная вкладка в списке, ◀ ▶ листают вкладки.
Ненужный канал или целую группу можно скрыть через меню (удерживать OK на канале).
Скрытое не показывается в списке и не листается ▲▼; вернуть - вкладка «Настройки» → «Скрытые».

Плейлист по ссылке обновляется сам при каждом запуске, без интернета работает сохранённая копия.
Сменить или обновить плейлист - вкладка «Настройки» в списке (последняя справа).

## Что понимает плейлист

- `#EXTINF` с `tvg-name`, `tvg-logo`, `tvg-chno`, `group-title`
- `#EXTGRP`, `#EXTVLCOPT:http-user-agent`, `#EXTVLCOPT:http-referrer`
- заголовки после `|` в ссылке (`User-Agent=...&Referer=...`)
- потоки HLS (m3u8) и MPEG-TS, ссылки без расширения тоже

## Сборка

GitHub Actions собирает APK на каждый push в ветку `efir-tv`
(`.github/workflows/efir-apk.yml`), готовый файл - в артефакте `efir-apk`.
APK подписан отдельным ключом этого приложения (`signing/efir.keystore`),
поэтому новые версии ставятся поверх старой без потери избранного.

Kotlin, minSdk 21, Media3/ExoPlayer 1.4.1, Coil для логотипов, ZXing для QR.
Шрифты Golos Text, Unbounded и IBM Plex Mono - под лицензией OFL (папка `licenses`).
